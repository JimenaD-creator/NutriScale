# NutriScale

**NutriScale** is a mobile app developed in **Kotlin** with **Android Studio** that allows users to calculate their Body Mass Index (BMI) and receive personalized recommendations about their nutritional status. The app is designed to be useful at any stage of life, providing dietary advice and exercise suggestions based on BMI results.

## Key Features

- **BMI Calculation**: Users can calculate their BMI by entering their gender, weight, and height.
- **Personalized Results**: The app displays a message indicating whether the user is in a normal, malnourished, overweight, or obese range.
- **Nutritional Advice**: Provides dietary recommendations based on BMI results.
- **Exercise Suggestions**: Offers suitable types of exercises to improve the user's physical condition.
- **Intuitive Interface**: User-friendly and easy-to-use design for an optimal user experience.

## Technologies used

- **Programming language**: Kotlin.
- **Development environment**: Android Studio.
- **Interface design**: XML for layouts and UI components.
- **Data persistence**: SharedPreferences to store user data.

### Prerequisites

- Android Studio (latest version recommended).
- Android device or emulator with API level 21 or higher.
  
### Steps to run the project

1. Clone the repository:
```bash
git clone https://github.com/JimenaD-creator/NutriScale.git
cd NutriScale
```
- Open the project in Android Studio:
  Select Open an existing Android Studio project and navigate to the project folder.
- Set up the emulator or connect a physical device:
  Make sure you have an emulator set up or an Android device connected with developer mode enabled.
- Run the app:
  Click the Run (▶️) button in Android Studio to build and run the app on your device or emulator.
